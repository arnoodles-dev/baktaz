# Health Data Integration Testing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Write comprehensive unit tests, widget tests, golden tests, and serverpod endpoint integration tests covering all Health Data Integration feature logic, UI, and backend API flows including HealthKit/Health Connect platform integration, step synchronization, device management, and one-authoritative-provider rule enforcement.

**Architecture:** Use `mockito` for mocked client and repository generation. Test Cubit state transitions with `bloc_test` and pure Dart `test`. Implement UI visual golden tests with `alchemist` under `test/widget/health/`. Conduct serverpod integration tests using `withServerpod` under `test/integration/health/`.

**Tech Stack:** `flutter_test`, `test`, `mockito`, `alchemist` (15% tolerance), `serverpod_test`.

**Spec:** `docs/superpowers/specs/health_data_integration_spec.md`

## Global Constraints

- Tests written ONLY AFTER all implementation tasks are completed.
- Target 100% coverage for Cubits and Repositories.
- Target 80% coverage for UI screens and widgets.
- AAA Pattern (Arrange-Act-Assert) strictly followed.
- Generated mock file resides in `test/utils/generated_mocks.dart`.
- Widget tests = golden tests (Alchemist, 15% tolerance).
- Server integration tests use `withServerpod` for real DB operations.
- Out-of-order sync protection and one-authoritative-provider rule must be explicitly tested.
- Revalidation on app resume must be tested.

### Test Coverage Depth Standard

Match `home_cubit_test` standard: **~8 tests per cubit** covering:
- Happy path for each action method
- Each distinct error state/failure path
- **Skip**: exhaustive permutations of provider state combinations (those go in device integration tests)

Example cubit test count:
```
HealthIntegrationCubit (~8 tests)
├── diagnose: 1 happy path + 3 error states = 4 tests
├── connect: 1 happy path + 1 error path = 2 tests
├── syncSteps: 1 happy path + 1 error path = 2 tests
└── revalidateOnResume: 1 test
Total: ~8 tests
```

import 'package:baktaz_server/src/features/health/endpoint/health_endpoint.dart';

import 'package:serverpod_test/serverpod_test.dart';
import 'package:test/test.dart';

void main() {
  withServerpod('Given HealthEndpoint', (endpoints, session) {
    group('connect', () {
      test('connects device and establishes authoritative provider', () async {
        final ConnectRequest request = ConnectRequest(
          deviceUuid: session.db.generateUuid(),
          platform: 'android',

          healthProvider: 'health_connect',

        final ConnectResult result = await endpoints.health.connect(session, request);

        expect(result.isNewDevice, isTrue);
        expect(result.isAuthoritative, isTrue);
      });

        // Connect first device
        final ConnectRequest firstDevice = ConnectRequest(
          deviceUuid: session.db.generateUuid(),
          platform: 'ios',
          deviceModel: 'iPhone 15',
          healthProvider: 'health_kit',
        );
        final ConnectResult firstResult = await endpoints.health.connect(session, firstDevice);
        expect(firstResult.isAuthoritative, isTrue);

        // Connect second device - should revoke first
        final ConnectRequest secondDevice = ConnectRequest(
          deviceUuid: session.db.generateUuid(),
          platform: 'android',
          deviceModel: 'Pixel 7',
          healthProvider: 'health_connect',
        );
        final ConnectResult secondResult = await endpoints.health.connect(session, secondDevice);

        expect(secondResult.isAuthoritative, isTrue);
        expect(secondResult.revokedPrevious, isTrue);
      });
    });

    group('syncSteps', () {
      test('accepts valid step sync and stores telemetry', () async {
        final SyncStepsRequest request = SyncStepsRequest(
          date: '2026-08-29',
          steps: 7500,
          syncSource: 'health_connect',
          deviceUuid: session.db.generateUuid(),
        );

        final SyncStepsResult result = await endpoints.health.syncSteps(session, request);

        expect(result.wasUpdated, isTrue);
        expect(result.steps, equals(7500));
      });

      test('protects against out-of-order sync requests', () async {
        // First sync with higher value
        final SyncStepsRequest firstSync = SyncStepsRequest(
          date: '2026-08-29',
          steps: 10000,
          syncSource: 'health_connect',
          deviceUuid: session.db.generateUuid(),
        );
        await endpoints.health.syncSteps(session, firstSync);

        // Second sync with lower value for same date - should be rejected
        final SyncStepsRequest secondSync = SyncStepsRequest(
          date: '2026-08-29',
          steps: 5000,
          syncSource: 'health_connect',
          deviceUuid: session.db.generateUuid(),
        );

        final SyncStepsResult result = await endpoints.health.syncSteps(session, secondSync);

        expect(result.wasUpdated, isFalse);
      });

      test('uses monotonic max() for same-day updates', () async {
        // First sync
        final SyncStepsRequest firstSync = SyncStepsRequest(
          date: '2026-08-29',
          steps: 5000,
          syncSource: 'health_connect',
          deviceUuid: session.db.generateUuid(),
        );
        await endpoints.health.syncSteps(session, firstSync);

        // Second sync with higher value - should update
        final SyncStepsRequest secondSync = SyncStepsRequest(
          date: '2026-08-29',
          steps: 8000,
          syncSource: 'health_connect',
          deviceUuid: session.db.generateUuid(),
        );

        final SyncStepsResult result = await endpoints.health.syncSteps(session, secondSync);

        expect(result.wasUpdated, isTrue);
        expect(result.steps, equals(8000));
      });
    });

    group('getStatus', () {
      test('returns connection status after device registration', () async {
        final ConnectRequest request = ConnectRequest(
          deviceUuid: session.db.generateUuid(),
          platform: 'android',
          deviceModel: 'Pixel 7',
          healthProvider: 'health_connect',
        );
        await endpoints.health.connect(session, request);

        final HealthConnectionStatus status = await endpoints.health.getStatus(session);

        expect(status.isConnected, isTrue);
        expect(status.provider, equals('health_connect'));
      });

      test('returns disconnected status when no devices registered', () async {
        final HealthConnectionStatus status = await endpoints.health.getStatus(session);

        expect(status.isConnected, isFalse);
      });
    });

      test('only one device can be authoritative at a time', () async {
        // Connect iOS device
        final ConnectRequest iosDevice = ConnectRequest(
          deviceUuid: session.db.generateUuid(),
          platform: 'ios',
          deviceModel: 'iPhone 15',
          healthProvider: 'health_kit',
        );
        await endpoints.health.connect(session, iosDevice);

        // Connect Android device
        final ConnectRequest androidDevice = ConnectRequest(
          deviceUuid: session.db.generateUuid(),
          platform: 'android',
          deviceModel: 'Pixel 7',
          healthProvider: 'health_connect',
        );
        final ConnectResult androidResult = await endpoints.health.connect(session, androidDevice);

        expect(androidResult.isAuthoritative, isTrue);
        expect(androidResult.revokedPrevious, isTrue);
      });
    });
  });

          .thenAnswer((_) async => TaskResult<bool>.left(Failure.platform('Service unavailable')));

      final TaskResult<HealthConnectionStatus> result =

      expect(
        result.fold((failure) => null, (status) => status),
        equals(HealthConnectionStatus.connected),
      );
    });

    test('syncSteps returns step count on success', () async {
      when(mockSyncStepsService.readSteps(any))
          .thenAnswer((_) async => TaskResult<int>.right(7500));

      final TaskResult<int> result = await repository.syncSteps(7500, '2026-08-29');

      expect(result.fold((failure) => 0, (steps) => steps), equals(7500));
    });

    test('syncSteps returns failure on service error', () async {
      const Failure failure = Failure.platform('Read failed');
      when(mockSyncStepsService.readSteps(any))
          .thenAnswer((_) async => TaskResult<int>.left(failure));

      final TaskResult<int> result = await repository.syncSteps(7500, '2026-08-29');

      expect(result.fold((f) => f, (_) => null), equals(failure));
