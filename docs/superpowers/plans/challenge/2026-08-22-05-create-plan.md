**Spec:** `docs/superpowers/specs/challenge/2026-08-22-05-create.md`

## Server-Driven Config

**`ChallengeConfig`** endpoint returns creation bounds:
- `minDurationDays`, `maxDurationDays` — duration slider range
- `maxParticipants` — max participants cap
- `minEntryFee`, `maxEntryFee` — entry fee slider range
- `maxHostCutPercentage` — host cut slider range
- `rewardModeMinParticipants` — floor per reward mode
