# Challenge Page Specification — Details

- **Date**: 2026-08-22
- **Parent Reference**: Part of the Challenge Page specification suite — see 00-overview.md

## Deep Link Behavior (Q67 Option B)
Navigation-layer guard-first: before pushing `DetailsRoute`, check auth → redirect to login if unauthenticated; check enrollment via root cubit → redirect to `/challenge` registered view if already-joined. `ChallengeDetailsCubit` never sees unauthenticated attempt — detail screen is pure "what this challenge is about" surface. Deep link always passes seed from navigation guard.

## Route

- `/challenge/detail/:id` — Challenge details preview & join confirmation

## 5.5 Challenge Details Screen (`ChallengeDetailsScreen`, `/challenge/detail/:id`) — "The Race Contract"

Layout: "The Race Contract" (combined Variations 1+3+4):

1. **Countdown Hero**: Gradient container with "STARTS IN" label + large mono digits countdown (e.g., `2d : 14h : 12m`) using `AppTextStyle.displayMedium` + `mono`. Signature element.
2. **Identity Block**: Title (`titleMedium`) + Challenge ID (`mono`) + Host name + Mode badge.
   - Full description display appears below the title.
3. **Divider**
4. **"TERMS" Section**: Eyebrow-style header (`titleSmall`, letter-spaced) followed by ledger rows separated by `BaktazDivider`:
   - Entry Fee: ₱500
   - Duration: 30 Days
   - Slots progress ring: 18/25
   - Prize Pool: ₱25,000 (`displayMedium`)
   - Tie-Breaker rule display
   - Rules & Guidelines link -> opens `rules_bottom_sheet.dart`
5. **Sticky Footer CTA**: `BaktazButton.primary` ("Join Challenge") pinned to bottom. Hidden for hosts (single-enrollment model: users in an active challenge are gated to the registered dashboard). Tapping triggers `non_refundable_disclaimer_dialog.dart`, then navigates to the payment feature. Insufficient wallet balance triggers `ConfirmationDialog` with cash-in CTA redirecting to `/account`.

**Post-Payment Flow**: Payment success shows a Challenge Payment Success Screen (Race Ticket pattern — same as create flow). Closing it pops back to `/challenge` where the root `ChallengeCubit` re-runs enrollment check and emits `.registered`.

## Entry Fee Disclaimer Flow

- Entry Fees are strictly non-refundable once paid.
- Before user confirms entry fee payment on `ChallengeDetailsScreen`, display explicit `ConfirmationDialog` with legal disclaimer confirming non-refundable terms.
- Sufficient balance processes entry fee and completes enrollment.
- Insufficient wallet balance triggers `ConfirmationDialog` with cash-in CTA redirecting to `/account`.

## Host Viewing Own Challenge

- For hosts viewing their own challenge detail: CTA hidden or replaced with host-appropriate action.
