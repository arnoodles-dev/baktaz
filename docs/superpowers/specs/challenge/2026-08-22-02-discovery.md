## 5.4 Public Challenge Page (`ChallengeExploreScreen`)

- **Route**: `/challenge/explore`
- **Layout**: Vertical scrollable list of public challenge cards with filter chips (entry fee range, duration, status) at the top.
- **Empty State (Q84 Option A)**: Illustration + "No public challenges match your filters" when list is empty. **Recovery**: "Clear Filters" CTA button resets ExploreFilter to defaults and refetches page 1.

### Search Bar Behavior

- **Debounced Search**: 300ms delay to avoid excessive API calls.
- **Search Scope**: Challenge Title + Host Name + Challenge ID.
- **Search Hint**: `BaktazTextField` hintText: "Search by title, host, or ID".

### Challenge Card Layout: "The Ledger" (Variation 1)

- Vertical hierarchy with `BaktazDivider` separators between rows. Entire card is tappable and redirects to `/challenge/detail/:id`.

1. **Header Row**: Title (`AppTextStyle.titleMedium`) + Challenge ID (`AppTextStyle.mono`)
2. **Description Row**: Description display rule: truncated to 1 line with ellipsis on explore cards.
3. **Divider**
4. **Host Row**: Host name + Mode badge (e.g. "Public" / "Private")
5. **Divider**
6. **Details Row**: Entry fee, Duration, `Starts in: ⏳` countdown timer
7. **Divider**
8. **Footer Row**: Slot progress ring (`BaktazProgressBar`) + Prize Pool (`AppTextStyle.displayMedium`)

### Filter Bottom Sheet: "The Ledger" (Variation 1)

- **Q77 Option A**: `ExploreFilter` freezed VO — `{rewardModes: List<RewardMode>, durations: List<int>, feeRange: {min, max}, sort: ChallengeSort, descending: bool}`. Default empty lists = all. `activeCount` computed getter for badge. Apply = commits to cubit, Clear/Reset = resets to defaults, both refetch page 1.

- Modal bottom sheet triggered from the filter icon/chip bar on `ChallengeExploreScreen`. Sheet uses `radiusXLarge` (24dp) top corners only; remaining corners follow system default.
- **Header**: Row with title "Filters" (`AppTextStyle.titleMedium`) on the left and a close icon button on the right. Padding `AppSizes.screenMarginH` horizontally, `AppSizes.m` vertically.
- **Sections** (grouped vertically with `Gap.medium()` between groups, `AppSizes.screenMarginH` horizontal padding):
  - **🏆 PRIZE POOL** (`AppTextStyle.titleSmall` header):
    - **Entry Fee**: `BaktazSlider` (or `Slider`) ranging 0–∞ with a trailing label showing current value (e.g. "₱0 – ₱∞").
    - **Prize Pool**: `BaktazSlider` ranging 0–∞ with trailing label.
  - **⏳ DURATION** (`AppTextStyle.titleSmall` header): `Wrap` of `FilterChip`s for **30 Days**, **60 Days**, **90 Days**. Multi-select checkboxes.
  - **🎯 MODE** (`AppTextStyle.titleSmall` header): `Wrap` of `FilterChip`s for **Winner-Takes-All**, **Top 3 Tiered Split**, **Equal Split**. Multi-select checkboxes.
  - **🔍 SORT BY** (`AppTextStyle.titleSmall` header): `DropdownButtonFormField<String>` with options **Participants**, **Start Time**, **Prize Pool**. Single-select.
  - **📈 ORDER BY** (`AppTextStyle.titleSmall` header): `Row` of two `FilterChip`s (or `ToggleButtons`) — **Ascending** / **Descending**. Single-select toggle.
  - **Sticky Footer**: `BottomSheet`-style pinned bar with `Gap.medium()` above it. Contains `BaktazButton.secondary` ("Reset", clears all selections) and `BaktazButton.primary` ("Apply", commits filters and closes sheet). Buttons span row evenly with `Gap.medium()` between.

## Description Display Rule

- Explore card descriptions are shown truncated to 1 line with ellipsis.
- Details screen shows full description below title.
- Summary sheet includes description in review.
