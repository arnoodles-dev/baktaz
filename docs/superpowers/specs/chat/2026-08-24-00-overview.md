## 1. Overview

The Chat Module provides real-time group messaging within active challenges. When a user joins a challenge, they are automatically added to the challenge's group chat room. The Chat screen is accessible via the bottom navigation bar (tab 3: Chat) and presents two sub-tabs:

1. **Chat tab** — real-time group text and photo messages for enrolled challenge participants.
2. **Events tab** — read-only system event messages (rank changes, milestones, anti-cheat, payouts, lifecycle).

Chat is **tightly coupled** to the challenge feature: if the user has no active challenge, chat shows an empty state with a CTA to join a challenge.

## 2. Goals / Key Features

**Goals**
- Real-time group text and photo messaging for active challenge participants via Serverpod WebSocket streams.
- **Photo Attachments**: Client-side compression (1080p, JPEG 80%, max 2MB) + Presigned S3 direct upload (zero backend server CPU/memory strain). Max 5 attachments per message (configurable via `AppConfig.maxChatAttachments`).
- **Separate EventMessage Engine**: Clean separation between user chat (`ChatMessage`) and read-only system events (`EventMessage`).
- **Admin Event Templates**: System event titles, bodies, and icons are dynamically rendered from customizable `EventTemplate` records managed via `baktaz_admin`.
- **25 System Event Types**: Real-time event notifications for rank changes, anti-cheat flagging, Sudden Death tie-breakers, HitPay payouts/refunds, and daily step milestones.
- Denormalized sender metadata to avoid JOINs on message fetch.
- Cursor-based pagination for message history.

**Non-Goals (V2)**
- Voice messages.
- Pin messages.
- Read receipts.
- Typing indicators.
- Direct 1-on-1 messaging.
- Message search.
- Push notifications for chat (handled by messaging transport).
