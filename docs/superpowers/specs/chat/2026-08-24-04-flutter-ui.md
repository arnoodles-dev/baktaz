### 4.7 Key Decisions

| Decision | Rationale |
|----------|-----------|
| Denormalized sender info | Simpler queries, acceptable data duplication |
| Cursor-based pagination | Stable across concurrent writes |
| Two WebSocket channels | `chat_room_messages_{id}` and `challenge_events_{id}` |
| Separate Chat & Event models | `ChatMessage` (user) vs `EventMessage` (system) |
| S3 Direct Presigned Upload | Zero backend server CPU/memory strain |
| Max 5 photo attachments | Configurable via `AppConfig.maxChatAttachments` |
| Admin Event Templates | `EventTemplate` dynamic string interpolation |
| Room lifecycle | Tightly coupled to challenge — no orphan rooms |
| **Bottom Nav Red Dot** | Red dot (no numbers) on Messages tab icon when `state.hasUnread` |
| **Sub-Tab Badges** | Red dot + unread count on each sub-tab header: `[ 💬 Chat 🔴 3 ]` & `[ ⚡ Events 🔴 1 ]` |
| **Instant Read Reset** | Selecting sub-tab resets its unread counter to 0 and updates `SharedPreferences` |

### 4.8 Unread Badge UI Integration

#### 1. Bottom Navigation Bar (`BaktazNavBar` / `MainScreen`)
- Tab 2 "Messages" icon listens reactively to `MessageCubit` state.
- When `state.hasUnread == true` (either `unreadChatCount > 0` or `unreadEventsCount > 0`):
  - Displays red dot badge (`CustomColors.error` / `#A32D2D`, 8dp diameter) positioned at top-right corner of `chat_bubble_outline` icon.
  - Clears automatically when both unread counters reach 0.

#### 2. In-Page Sub-Tab Headers (`MessagePage`)
- `MessagePage` renders two sub-tab headers at top:
  1. **Chat Sub-Tab**: `[ 💬 Chat ]`
     - If `unreadChatCount > 0`: renders `[ 💬 Chat  🔴 3 ]` badge pill (`BaktazStatusBadge.error` / `CustomColors.error` background, white text).
  2. **Events Sub-Tab**: `[ ⚡ Events ]`
     - If `unreadEventsCount > 0`: renders `[ ⚡ Events  🔴 1 ]` badge pill.
- Tapping a sub-tab triggers `cubit.selectSubTab(index)`, which instantly clears that sub-tab's unread counter to 0.

### 4.9 Key UI Components

1. **`MessagePage`** — main chat view with sub-tabs (Chat / Events) and unread badge headers.
2. **`MessageTile`** — chat message bubble:
   - Displays sender name, avatar (`BaktazAvatar`), timestamp, text content.
   - Displays grid of attached photos (1–5 images) via `Shimmer` thumbnail placeholders.
   - Tapping an image opens full-screen image viewer modal.
3. **`MessageInputBar`**:
   - `BaktazTextField` for text input.
   - Photo attachment icon button -> triggers image picker (max 5 photos).
   - Send button -> disables while uploading or when empty.
4. **`AttachmentPickerPreview`**:
   - Pinned preview bar above input bar showing selected image thumbnails with `(X)` remove buttons.
5. **`EventsPage`**:
   - Read-only timeline feed of system events (`EventMessage`).
   - Renders event icon (`warning_amber`, `trophy`, `bolt`), title, body, and timestamp.
6. **`EmptyChatPage`**:
   - Displayed when user is not enrolled in an active challenge.
   - Includes CTA: "Explore Challenges" -> redirects to `/challenge/explore`.
