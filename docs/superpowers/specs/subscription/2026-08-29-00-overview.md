## 1. Feature Summary

The Host Subscription feature enables users to upgrade from a Free Regular User to a Subscribed Premium Host tier in Baktaz. Premium Hosts unlock the entitlement to earn and retain a **Host Cut** on challenges they host.

### Key Capabilities
1. **Tier Distinction**: Regular User (Free) vs Subscribed Premium Host.
2. **Subscription Packages**: Configurable plans (Monthly, 3-Month, Annual) loaded from server database.
3. **Vouchers**: Discount codes (percentage, fixed amount, free trial days) with plan-specific constraints, 1-time-per-user limits, optional usage caps, and expiration dates.
4. **HitPay Native Recurring Billing**: Credit/Debit card tokenization via HitPay hosted checkout page; HitPay handles automatic cycle renewals. Platform absorbs all processing fees and VAT.
5. **No Refunds & Clean Lifecycle**: Cancellations take effect at current period end (`expiresAt`); no partial refunds.
6. **Strict Point-In-Time Host Cut Forfeiture**: At challenge completion (`challenge.expiresAt`), host MUST possess an active, unexpired subscription. If expired, net host cut forfeits to ₱0.

## 3. Explicit Architecture Decisions

- **HitPay Cards Only**: Payment rail limited strictly to Cards via HitPay hosted recurring billing. No native App Store / Google Play In-App Purchase.
- **Platform Fee Absorption**: Prices displayed are final. Platform absorbs HitPay card processing fees (~3.5%) + 12% VAT on fees.
- **Shared Payment Infrastructure**: Saved HitPay payment tokens stored in `saved_payment_method` table for future reuse in Manage Payment screen.
- **First-Cycle Voucher Discount**: Vouchers discount initial charge amount only; auto-renewals occur at base plan price.
- **Admin-Defined Vouchers**: Human-readable uppercase promo codes (e.g. `WELCOME20`, `LAUNCH50`), mapped to specific plans via `voucher_plan` junction table.
