#### Key Components:
- **`HostSubscriptionBanner`** (reusable widget): Shows current tier badge. On AccountPage: compact. On HostSubscriptionScreen: expanded with upgrade CTA.
- **`PlanSelectorWidget`**: Radio-group cards. Monthly / Quarterly / Annual. Selected state highlighted. Shows discount badge (e.g., "BEST VALUE", "25% OFF").
- **`VoucherInputWidget`**: Text field + Apply button. Real-time validation on blur. Shows discounted price when valid. Error inline if invalid.
- **`SubscribeButton`**: Primary `BaktazButton`. Disabled until package selected. Opens HitPay checkout WebView.
- **Bottom disclaimer**: Auto-renewal notice + cancellation policy.

### 1.4 `VoucherInputWidget`

```text
VOUCHER CODE
[ WELCOME20                    ]  [ Apply ]
     ↑                                    ↑
  TextField                          Button
  
  ✓ Valid! 20% off first cycle → ₱239.20
  (Original: ₱299.00)
```

**States:**
1. **Idle**: Empty field, Apply enabled.
2. **Validating**: Spinner on Apply, field disabled.
3. **Valid**: Green checkmark, discounted price shown, Apply → "Applied".
4. **Invalid**: Red error text below field, "Invalid/expired code".

**Behavior:**
- Validate on field blur OR Apply tap (debounced 300ms).
- `voucherInput` stored in cubit state for persistence across validation calls.
- Clear button appears when code applied (allows switching voucher).

### 1.5 `HitPayCheckoutWebView`

Full-screen WebView wrapper for HitPay hosted checkout page.

```dart
class HitPayCheckoutWebView extends StatefulWidget {
  final String checkoutUrl;
  final ValueChanged<CheckoutResult> onResult;
}
```

**Navigation Interception:**
- Monitors URL changes.
- Detects redirect to `redirectUrl` (configured in server checkout).
- Expected redirect format: `baktaz://subscription/success?subscriptionId=...` or `baktaz://subscription/cancelled`
- Extracts `subscriptionId` and status, calls `onResult`.
- Closes WebView, returns to `HostSubscriptionScreen`.

**Loading State:** Shows `BaktazShimmer` overlay while WebView loads.

## 2. Design Tokens & Styling

- **Colors**: `context.colorScheme` — primary for selected plan, surfaceContainer for cards, error for validation errors.
- **Typography**: `Theme.of(context).textTheme.*` (headlineMedium for prices, bodyMedium for labels) and `BaktazType.*` for display styles.
- **Spacing**: `BaktazSpacing.*` / `BaktazRadius.*`.
- **Badges**: `BaktazStatusBadge` for "BEST VALUE", "25% OFF", "Free Badge".
- **Dark Mode**: Automatic via theme — surface lightening, no shadows.

## 4. Accessibility

- All interactive elements have semantic labels.
- Color contrast meets WCAG AA (validated via design system).
- Focus order: Plan cards → Voucher field → Apply button → Subscribe button.
- WebView has accessible name "HostPay Subscription Checkout".
